구글 지도 API 키 입력

이 페이지는 구글 지도 JavaScript API로 실제 지도를 보여줘요. 본인 구글 클라우드 계정의 API 키를 한 번만 입력하면 이 브라우저에 저장돼요 (파일에는 저장되지 않음).

  1. console.cloud.google.com 에서 프로젝트 만들기 → 결제 계정 연결
  2. 'Maps JavaScript API'와 (도보 경로용) 'Directions API' 사용 설정
  3. 사용자 인증 정보 → API 키 만들기 → 웹사이트 제한에 http://localhost:8000/* 추가
  4. 터미널에서 cd ~/honeymoon-prague && python3 -m http.server 8000 실행 후 http://localhost:8000/honeymoon-map.html 접속
